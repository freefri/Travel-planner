How to render a trip here

  1. Write the trip as JSON following the JSON Schema at https://freefri.github.io/Travel-planner/preview/schema.json. It explains every field and includes an example.
  2. Encode that JSON as base64url.
  3. Share https://freefri.github.io/Travel-planner/preview/#data: followed by the encoded text.
